저장 방식 안내
GitHub Pages는 사이트 화면을 공개하지만, 작성한 글·사진·회차 기록은 이 브라우저의 IndexedDB에만 저장되고 GitHub에 업로드되지 않습니다. GitHub Pages 주소는 다른 사람도 접속할 수 있지만, 브라우저에 저장한 내용은 공유되지 않습니다. 브라우저 데이터 삭제·시크릿 모드·다른 브라우저 사용 시 자료가 보이지 않을 수 있으니, 사진이 늘어날수록 상단의 ‘백업’으로 JSON 파일을 정기적으로 저장하세요.
